Fonte oficial

Painéis da ABVE

Relatórios Power BI publicados pela Associação Brasileira do Veículo Elétrico. São os dados de referência do setor — frota, vendas, eletropostos, ônibus e distribuição geográfica.

Por que estes painéis abrem aqui e o mapa do carregados não: a ABVE publicou os relatórios com a opção “Publicar na web” do Power BI, que autoriza a incorporação em qualquer site. Já o carregados.com.br envia x-frame-options: SAMEORIGIN, instruindo o navegador a recusar. É decisão de cada fonte, não limitação do nosso lado.

Por que o mapa antigo falhava

O portal carregados.com.br responde com x-frame-options: SAMEORIGIN e frame-ancestors 'self'. Isso instrui o navegador a recusar a página dentro de um <iframe> de outro domínio — daí a mensagem de conexão recusada. Nenhum ajuste de parâmetro contorna a política; a saída é renderizar o mapa localmente, que é o que esta seção faz.

Como se classificam

As 5 categorias ABVE

Números da coleta atual. Passe o cursor, toque ou use o teclado para virar cada cartão e ver a definição.

BEV

100% elétrico

Movido exclusivamente por bateria. Zero emissão no escapamento e a maior eficiência energética entre todas as categorias.

PHEV

Híbrido plug-in

Bateria recarregável na tomada somada a um motor a combustão, que assume quando a carga elétrica acaba.

HEV

Híbrido convencional

Recarrega apenas pela frenagem regenerativa e pelo motor a combustão. Não tem tomada: nunca depende de eletroposto.

MHEV

Híbrido leve

Sistema de 48V que assiste o motor térmico em arrancadas e retomadas, cortando consumo sem tração puramente elétrica.

FCEV

Célula de hidrogênio

Gera a própria eletricidade a bordo a partir do hidrogênio comprimido, emitindo somente vapor de água.

De onde vêm os dados

Fontes de dados

  • carregados.com.br — base principal de eletropostos, pela API pública de mapa do portal: coordenadas, rede, potência e confiabilidade.
  • OpenStreetMap — eletropostos complementares, com conectores e horários, via Overpass API. Licença ODbL 1.0.
  • IBGE — malha territorial das UFs, usada para atribuir o estado de cada ponto.
  • carregados.com.br — ofertas de veículos, lidas dos dados estruturados schema.org que a própria página publica.
  • ABVE — painéis Power BI oficiais do setor, incorporados na seção de dashboards.
  • AwesomeAPI — cotação USD→BRL para converter preços de referência internacionais.
  • Open-Meteo — clima e geocodificação do widget flutuante.

A SustAmbiTech atua como agregadora de dados públicos: não gera dados primários, credita a origem e mantém o pipeline aberto para auditoria.

Dúvidas comuns

FAQ

De onde vêm os eletropostos do mapa?

Do OpenStreetMap, consultado pela Overpass API com um recorte no bounding box do Brasil. Cada ponto recebe a UF por teste de ponto-em-polígono contra a malha territorial do IBGE, o que também descarta pontos de países vizinhos que caem dentro do retângulo. Os dados são distribuídos sob a licença ODbL 1.0 e exigem atribuição.

De onde vêm os 12 mil eletropostos?

De duas fontes combinadas. A principal é a API pública de mapa do carregados.com.br (/api/mobile/v1/map/stations), que responde GeoJSON com coordenadas, rede, potência e índice de confiabilidade — foram 12.009 pontos. A ela somamos 155 registros do OpenStreetMap que não tinham equivalente por perto; outros 228 do OSM foram reconhecidos como repetidos e descartados por proximidade (150 m). A coluna fonte no banco diz a origem de cada linha, e os dois conjuntos nunca se misturam: o subconjunto do OSM é ODbL e exige atribuição e compartilhamento igual.

Vocês podem usar os dados do carregados.com.br?

A coleta é para este projeto de extensão universitária, sem fim comercial e com crédito à fonte em todas as telas. O robots.txt do portal declara Allow: / e Content-Signal: ai-train=yes, search=yes, ai-input=yes, e a rota consultada é uma API pública do próprio site. Cada registro guarda o link da página de origem. Ainda assim, é uma base proprietária, não dado aberto: quem quiser reaproveitar deve procurar o portal. Pedidos de correção ou remoção podem ser feitos via GitHub Issues e serão atendidos.

Por que o mapa antigo mostrava “conexão recusada”?

Porque o carregados.com.br envia os cabeçalhos x-frame-options: SAMEORIGIN e content-security-policy: frame-ancestors 'self'. Eles mandam o navegador bloquear a página dentro de um <iframe> hospedado em outro domínio. É uma decisão do site de origem: não existe parâmetro, proxy simples ou ajuste de código no nosso lado que a contorne legitimamente. Por isso o mapa foi reconstruído aqui.

Os preços dos veículos são oficiais?

Os preços são reais, lidos dos anúncios publicados em carregados.com.br através do bloco schema.org/Vehicle que a própria página expõe para buscadores. O que é estimativa é a ficha técnica associada a cada modelo — autonomia, capacidade de bateria e tipo de conector —, compilada de material público dos fabricantes para permitir o cruzamento por categoria ABVE.

Como funciona a conversão de dólar para real?

Alguns modelos têm MSRP de referência do mercado internacional em dólar. Na hora de gerar o banco, o script etl/fetch_cambio.py consulta a cotação de venda na AwesomeAPI (com a open.er-api.com como reserva) e grava tanto o valor em dólar quanto o convertido em reais, junto com a data da cotação. A comparação serve para contexto de mercado, não como preço praticado no Brasil.

O botão de clima coleta minha localização?

Só se você clicar em “Usar minha localização” e autorizar no navegador. A coordenada é enviada diretamente à Open-Meteo para a consulta e não passa por nenhum servidor nosso — o site é estático. A última cidade escolhida fica salva apenas no localStorage do seu próprio navegador.

Dá para extrair a base que alimenta o Power BI publicado?

Não. Um relatório publicado com “Publicar na web” expõe o visual renderizado, não o modelo semântico por trás dele. Ler o dataset exige autenticação no workspace e uso da API do Power BI ou do XMLA endpoint — algo que só o dono do relatório pode fazer, com as próprias credenciais. O caminho correto é o inverso: publicar um relatório novo sobre o banco aberto deste repositório, como descrito em docs/POWERBI.md.

Como reproduzo os dados na minha máquina?

Com Python 3 instalado, rode em sequência python etl/fetch_eletropostos.py, python etl/fetch_carros.py, python etl/fetch_cambio.py e python etl/build_db.py. Nenhuma chave de API é necessária. O resultado aparece em data/ e em assets/data/, e o site passa a refletir a nova coleta.

Preciso de alguma chave de API?

Não para o que está no repositório. Se quiser ampliar a cobertura de eletropostos, o OpenChargeMap oferece uma base bem maior, mas exige uma chave gratuita criada por você em openchargemap.org. Como o site é estático e público, uma chave colocada no front-end fica visível para qualquer visitante — use-a no ETL, que roda na sua máquina.

Com que frequência os dados são atualizados?

A cada execução do pipeline, que grava uma linha datada na tabela snapshots. O rodapé e a seção de números mostram a data da coleta vigente, então a página sempre diz de quando são os dados que você está vendo.
